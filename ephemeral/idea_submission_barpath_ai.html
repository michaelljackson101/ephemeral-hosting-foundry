# Idea Submission: BarPathAI (Olympic Weightlifting Form & Biomechanics CV)

## 1. Concept Overview

**BarPathAI** (alternate name: **OlympicFormCV**) is an AI-first multi-camera computer vision capability engineered to evaluate an Olympic weightlifter's movement form during the **Snatch** and **Clean & Jerk**. 

Positioned at three standardized camera angles representing the official IWF referee positions (**Center 0°**, **Left 45°**, **Right 45°**), the system captures high-framerate video, extracts 3D human pose keypoints and barbell trajectories, checks technical execution against International Weightlifting Federation (IWF) penalty rules, and delivers instantaneous, actionable coaching critique.

## 3. Core Capabilities & Architecture

### 1. Ingestion & Multi-Camera Alignment
* **Ingest Protocol**: Pre-trimmed MP4 clip ingestion or live stream capture via RTSP/MediaMTX.
* **Temporal Sync**: Frame offset normalization using an acoustic (hand-clap) or visual flash impulse trigger.
* **Spatial Calibration**: Camera projection matrix estimation using ChArUco target markers or feature matching via LightGlue.

### 2. Pose & Barbell Tracking Engine
* **2D Human Keypoint Detection**: 17 COCO keypoints per view at 60+ FPS using **RTMPose** or **YOLOv11-Pose**.
* **Barbell Plate Detection**: Real-time barbell tracking via color mask segmentation (standard IWF bumper plate colors) or bounding-box detection.
* **3D Trajectory Reconstruction**: Multi-view algebraic triangulation mapping $(x, y, z)$ coordinates in a unified world space.

### 3. Kinematic Metric Engine
* **Bar Path Trajectory**: Calculating vertical peak displacement, velocity profiles, acceleration spikes, and horizontal $S$-curve drift.
* **Biomechanical Angles**: Knee flexion/valgus, hip angle at receiving position, back torso angle relative to floor during First and Second Pull.
* **Phase Segmentation**: Automatic detection of key movement phases:
  1. *First Pull* (Floor to knee)
  2. *Second Pull* (Knee to explosive hip extension)
  3. *Turnover & Receiving* (Drop under bar to catch)
  4. *Recovery & Lockout* (Standing up to completion)

### 4. IWF Rule Penalty & Virtual Judge Engine
* **Elbow Press-Out Detection (IWF Technical Rule 2.5.1)**: Monitoring wrist-to-elbow vector stability post-catch to detect non-continuous extension or arm re-bending.
* **Foot Movement & Foot Out-of-Bounds**: Tracking ankle/toe keypoints relative to platform boundary markers.
* **Lowering Before Down Signal**: Validating overhead lock stability duration.

### 5. Multimodal VLM Coaching Engine
* **Input Payload**: 4 sampled keyframe grids (0°, 45°L, 45°R) at peak phases + kinematic metric JSON summary.
* **VLM Reasoning**: Prompts **Gemini 2.0 Flash** / **Qwen2-VL** with the IWF rubric to produce:
  * **Judge Decision**: 3 White Lights (Valid) / Red Light (Penalty Reason).
  * **Efficiency Score**: Form rating (0–100%).
  * **Actionable Coaching Cues**: 3 targeted technical fixes for the athlete.

## 4. Weekend MVP Target (v0.1)

The initial version (**BarPathAI v0.1**) focuses on high-impact offline clip analysis:

1. **Clip Ingestion**: Ingest 3 pre-recorded MP4 clips from smartphones in a home studio.
2. **Keypoint & Bar Path Extractor**: Python script running YOLOv11-Pose and color-masked bar path plotting.
3. **Press-Out & Depth Evaluator**: Algorithmic check for catch depth and elbow angle variance.
4. **VLM Feedback Card**: Automated visual scorecard generated via Gemini API call.
